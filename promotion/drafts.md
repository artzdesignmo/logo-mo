## Reddit r/SideProject

**Title:** I built an offline logo studio — type a name, get 12 original logo concepts, zero API keys

**Body:**
Hey r/SideProject! I just shipped **Logo Mo**, a generative logo studio that runs 100% in the browser.

Type a brand name → a seeded design engine draws 12 original concepts across 4 families (monogram / wordmark / badge / abstract mark), with curated palettes and open fonts. Click any concept for palette variants, business-card + app-icon mockups, and real exports: SVG, PNG (512/1024/2048), copy-SVG.

Why offline? Every logo generator I found needs an AI API key or a backend. This one is a single `index.html`, zero dependencies — the "AI" is a seeded PRNG + hand-built SVG generators. Same name = same set, shuffle = fresh set. PNG export even embeds the font so it's pixel-faithful.

MIT licensed, free forever. Would love feedback on the generator families — what logo styles am I missing?

分享一个刚完成的 side project：**Logo Mo**，纯前端、零依赖、完全离线的 Logo 生成工作室。
